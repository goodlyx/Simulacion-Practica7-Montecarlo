# Repositorio: Introducción a SimPy

Bienvenido a este repositorio de la materia de Simulación. El propósito de este proyecto es documentar y explicar el funcionamiento de **SimPy**, un framework de Python utilizado para la simulación de eventos discretos.

## Contenido del Repositorio

Este repositorio está estructurado en los siguientes archivos Markdown:

*   [**`que_es_simpy.md`**](que_es_simpy.md): Contiene la investigación teórica sobre qué es SimPy, sus características principales y cómo funciona mediante generadores.
*   [**`ejemplo1_reloj.md`**](ejemplo1_reloj.md): Un ejemplo básico que muestra cómo crear un entorno y un proceso sencillo (un reloj).
*   [**`ejemplo2_banco.md`**](ejemplo2_banco.md): Un ejemplo intermedio utilizando Recursos (`Resource`) para simular la fila de un banco.
*   [**`ejemplo3_gasolinera.md`**](ejemplo3_gasolinera.md): Un ejemplo avanzado que implementa Contenedores (`Container`) para simular el inventario de una gasolinera.
