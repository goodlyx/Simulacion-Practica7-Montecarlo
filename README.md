# Repositorio: Investigación Método Montecarlo

Bienvenido al repositorio de la Práctica 7 de la materia de Simulación. Este repositorio contiene la investigación formal sobre el Método Montecarlo, así como ejemplos prácticos de su aplicación programada mediante la generación de números pseudoaleatorios.

## Contenido del Repositorio
* [**`montecarlo.md`**](montecarlo.md): Explicación teórica detallada del Método Montecarlo, su origen, metodología y formulación matemática.
* [**`ejemplo1.md`**](ejemplo1.md): Ejemplo de aplicación 1. Estimación del valor de Pi (π) mediante el lanzamiento de dardos aleatorios.
* [**`ejemplo2.md`**](ejemplo2.md): Ejemplo de aplicación 2. Simulación de inventarios estocásticos (demanda aleatoria) para maximización de utilidades.
